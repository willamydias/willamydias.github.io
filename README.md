# Willamy Mamede — Website Pessoal & Portfólio

Repositório da página pessoal hospedada no GitHub Pages: [https://willamydias.github.io/](https://willamydias.github.io/)

## Visão Geral

Website pessoal técnico focado em Ciência de Dados, Modelos Preditivos de Machine Learning, Visão Computacional e Engenharia de Software.

### Recursos da Página
- **Destaques Selecionados:** Curadoria dos principais projetos de pesquisa e aplicações em produção.
- **Explorador Dinâmico de Repositórios:** Busca instantânea e filtros por linguagem (Python, Rust, TypeScript, Jupyter) consumindo a API pública do GitHub.
- **Formação & Pesquisa:** Síntese da trajetória acadêmica (Mestrado) e áreas de domínio técnico.
- **Presença Digital:** Links profissionais diretos para contato e colaborações técnicas.

### Tecnologias Utilizadas
- HTML5 Semântico (acessibilidade WCAG 2.1 AA)
- CSS Moderno com Design Tokens (paleta Dark Mode técnico inspirada em Geist/Linear)
- JavaScript assíncrono puro (Vanilla JS com fallback offline de contingência)
